# v0.4 · Labs, manual

Not started.

## Goal

Turn lab results into data you can follow over time.

## Scope

**In.** Manual entry of lab reports with values, units and reference ranges, an analyte catalog, unit normalization and a trend chart per analyte.

**Out.** Extraction from PDFs, which is v0.5, and any interpretation of results beyond the printed reference range.

## Entry criteria

- [ ] v0.3 shipped, so a report can be attached to the file it came from

## Decisions

- [ ] How to identify analytes, with an own catalog or a standard code system
- [ ] Storing original and normalized values
- [ ] Handling non-numeric results

## Work plan

- [ ] `core/domain` · Lab report, result value as numeric, qualitative or bounded ("<0.5"), unit and reference range as printed. Unit conversion as pure functions with property tests.
- [ ] `core/application` · Propose, confirm and correct lab reports, and a trend query per analyte. Unit tests.
- [ ] `db` · Lab report, result and analyte catalog tables, seeded catalog for common analytes, migration. Integration tests.
- [ ] `apps/api` · Lab entry and trend routes. Route tests.
- [ ] `apps/mobile` · Lab entry form, which v0.5 reuses as its review screen, and a trend chart showing reference ranges without verdicts.
- [ ] `agent` · Read tool for lab results, Reads eval cases updated.

## Acceptance criteria

- [ ] Original value and unit are always stored exactly as entered
- [ ] One analyte from two labs with different units appears as one coherent trend
- [ ] Non-numeric results ("negative", "<0.5") are stored and displayed correctly
- [ ] Reference ranges come from each report, and the chart shows them without any verdict
- [ ] Release checklist complete

## Risks

| Risk | Mitigation |
|---|---|
| A wrong unit conversion silently corrupts a trend | Conversions are pure, property-tested, and the original value is always kept |
| The chart implies a judgment through color | Reference bands are neutral, and no value is colored as good or bad |

## Demo script

1. Enter two glucose results from different labs in mg/dL and mmol/L.
2. Open the glucose trend and show one coherent line with each report's own range.
3. Enter a "negative" result and show it on the timeline.
