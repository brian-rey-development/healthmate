# v0.5 · Labs, extracted

Not started.

## Goal

Get lab values from PDFs into HealthMate with less effort and no loss of accuracy.

## Scope

**In.** Extraction of lab results from uploaded PDFs into proposals, and a review screen built on the v0.4 form. A golden dataset and an extraction eval that blocks regressions in CI.

**Out.** Extraction from images or handwritten notes, and saving anything without review.

## Entry criteria

- [ ] v0.4 shipped, so extracted values have a form to be reviewed in

## Decisions

- [ ] Golden dataset composition and labeling rules
- [ ] Metric per field and numeric tolerance
- [ ] Regression threshold that blocks a merge

## Work plan

- [ ] `evals/datasets` · Golden dataset of 30 to 50 labeled synthetic or redacted reports, with labeling rules written down.
- [ ] `evals` · Extraction scorer with field-level precision, recall and F1, plus cost and latency per report, wired into CI.
- [ ] `agent` · Page selection that sends only result pages, and extraction into lab report proposals that record the source page. Instructions inside the PDF are treated as data.
- [ ] `apps/api` · Extraction job and review routes. Route tests.
- [ ] `apps/mobile` · Review screen showing each value next to its page.

## Acceptance criteria

- [ ] Field-level F1 above the agreed threshold on the golden set
- [ ] Nothing extracted is saved without review
- [ ] Each extracted value records the page it came from
- [ ] Instructions embedded in a PDF are not followed (eval case)
- [ ] Only pages containing results are sent to the model
- [ ] Cost and latency per report are measured and reported
- [ ] A regression on the golden set blocks the merge
- [ ] Release checklist complete

## Risks

| Risk | Mitigation |
|---|---|
| The golden set does not resemble real reports | Built from redacted real layouts from several labs, not one template |
| Review fatigue lets wrong values through | Review screen puts each value beside its source page and highlights low-confidence fields |

## Demo script

1. Upload a lab PDF and open the review screen.
2. Fix one value, confirm the report, and show the trend updated.
3. Show the committed eval summary with F1, cost and latency.
