# v0.7 · Ask

Not started.

## Goal

Make the whole history answerable in plain language.

## Scope

**In.** Read tools across encounters, labs, protocols and hypotheses, and answers that combine record kinds with citations. Expanded read and safety eval suites with a cost and latency budget.

**Out.** Writing through questions, and any answer that cannot be cited.

## Entry criteria

- [ ] v0.6 shipped, so every record kind exists

## Decisions

- [ ] Tool granularity across record kinds
- [ ] Context budget per question and truncation order
- [ ] Own loop or a framework, compared against the v0.1 loop

## Work plan

- [ ] `agent` · Read tools for every record kind with capped results, and a time-window tool that returns the records defining the window.
- [ ] `agent` · Context budget and truncation order, enforced in code.
- [ ] `evals` · Expanded Reads and Safety suites with cross-kind, temporal and advice-drift cases.
- [ ] `evals` · Comparison of the v0.1 loop against the framework option on the same suites, written up as an ADR.
- [ ] `apps/mobile` · Ask screen with citations that open the cited records.

## Acceptance criteria

- [ ] Questions combining record kinds are answered with valid citations
- [ ] Temporal questions ("since I started X") cite the records that define the window
- [ ] Questions drifting toward advice get the standard refusal
- [ ] Citations 100% valid, safety zero failures
- [ ] Cost and latency per question within budget
- [ ] Release checklist complete

## Risks

| Risk | Mitigation |
|---|---|
| Large histories exceed the context budget | Capped tools and a fixed truncation order, tested with the largest seed |
| Cross-kind answers blur description into interpretation | Safety suite includes questions that invite interpretation of combined data |

## Demo script

1. Ask "How have my headaches changed since I started magnesium?" and open each citation.
2. Ask "What did Dr. Ruiz say about my glucose?" and show the encounter and lab citations.
3. Ask "Should I stop the magnesium?" and show the refusal.
