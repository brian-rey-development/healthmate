# v0.6 · Experiments

Not started.

## Goal

Help the person test their own ideas and see only the conclusions that the data supports.

## Scope

**In.** Protocols with dose, start and end. Hypotheses with a target metric that move from idea to experiment to closed. A before and after view that shows only what the data supports.

**Out.** Suggesting ideas, recommending protocols, or any causal claim.

## Entry criteria

- [ ] v0.5 shipped, so lab values are available as target metrics

## Decisions

- [ ] Hypothesis states and what each transition requires
- [ ] Handling dose changes mid-experiment
- [ ] Minimum data required to show a comparison

## Work plan

- [ ] `core/domain` · Protocol and hypothesis with an explicit state machine, overlap detection, and a comparison that returns "changed", "no clear change" or "not enough data". Property-based tests for every transition and for the data minimum.
- [ ] `core/application` · Start, adjust and stop protocols, open, start and close hypotheses, and compute comparisons. Unit tests.
- [ ] `db` · Protocol and hypothesis tables, migration. Integration tests.
- [ ] `agent` · Tools to record ideas the person states and to read comparisons. Experiments eval suite.
- [ ] `apps/mobile` · Protocol and hypothesis screens and the before and after view with overlap warnings.

## Acceptance criteria

- [ ] An idea cannot become an experiment without a target metric
- [ ] Illegal state transitions are impossible, proven with property-based tests
- [ ] Comparisons below the data minimum are not shown
- [ ] Overlapping protocols are always flagged
- [ ] "No clear change" and "not enough data" are shown as results
- [ ] The agent records ideas the person states and never suggests new ones
- [ ] Experiments eval suite passes
- [ ] Release checklist complete

## Risks

| Risk | Mitigation |
|---|---|
| A before and after chart reads as proof of cause | Copy never says "caused", overlaps are always shown, and the data minimum is enforced in the domain |
| The agent drifts into suggesting experiments | Experiments eval includes cases that invite suggestions and fail on any |

## Demo script

1. Say "I want to see if magnesium helps my headaches" and confirm the idea.
2. Start the experiment with headache frequency as the target metric.
3. Start a second protocol the same week and show the overlap warning.
4. Open the comparison and show "not enough data" before the minimum is reached.
